Orion is an AI assistant that works inside Roblox Studio and helps you build your game. It is subscription based, with a generous free tier.

This repository is where Orion's public release builds are published. Orion's source code is closed and is not in this repository.

## Get Orion

Download Orion and create an account at **[get-orion.com](https://www.get-orion.com)**. Release builds are also attached to this repository's [Releases](https://github.com/nsawill1405/Orion-Releases/releases) page when they are published.

## Feedback and bugs

Open an [issue](https://github.com/nsawill1405/Orion-Releases/issues) with:

- what you did and what you expected to happen;
- your Orion version and operating system;
- any error shown in Orion or in the Studio Output window.

Don't paste API keys, tokens or other private data into an issue.
